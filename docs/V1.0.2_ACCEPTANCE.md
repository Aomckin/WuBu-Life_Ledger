# 物簿 v1.0.2 验收

2026-11-16 在临时 Go 服务和 SQLite 数据库上验收。

| 场景 | 结果 |
| --- | --- |
| A 视觉分离 | Edge 1440px 和 390px 通过。首页是模块入口。物品、金额账户和 AI 有各自的导航和配色。工作区表格与两个快捷表单在手机宽度下通过溢出检查。 |
| B 功能独立 | 物品购入、维护、售出、退货和库存查询通过。账户、流水编辑、充值、退款、原生账单和对账通过。AI 服务未配置时可以录音与暂存，暂存不写库存。 |
| C 脚本边界 | 物品、金额账户和 AI 各自加载业务代码。通用代码处理请求、布局和格式化。旧混合首页及其业务脚本已移除。 |
| D 可选关联 | 从物品选择资金流水、从交易后补购入均通过。模拟后补购入已提交但浏览器未收到响应，刷新重试复用幂等键，库存只增加一次，账户余额保持原值。 |
| E 回归 | Go test、vet、前端静态检查、四套 Edge 浏览器用例和真实朝汐 SDK 只读集成均通过。数据库结构继续使用 Schema 17。 |
| F 故障隔离 | 分别注入物品、财务和 AI 接口的 503。公共入口只标记对应概览不可用。其他工作区仍可打开，普通页面未请求其他领域的数据。原有链接继续有效。 |

首页和工作区视觉代码由 `agy` 调用 Gemini 3.8 Flash (High) 生成。全量文件改写在产出部分首页文件后超时，Codex 采用独立生成的视觉代码完成业务脚本拆分和验收。录音测试使用 Edge 模拟麦克风。验收未调用物簿运行时的真实分析模型。

## 本机部署

2026-11-16 正式实例切换至 v1.0.2，仍监听 `127.0.0.1:8026`。停服后的 SQLite 备份及 v1.0.1 程序保存于 `.runtime/v102-release-20261116120223-c07b4d/backup`。上线后正式库保持 Schema 17，38 张表共 725 行与备份逐行一致，完整性和外键检查均通过。Edge 在正式站点检查了三个工作区、两个快捷表单、旧链接与 390px 导航，未提交账本操作。

上线后修复首页两处未被本地图标字体收录的连字，并加入浏览器回归。正式首页在 1928px 和 390px 下的三个图标均渲染为 22px 单字形，位于各自的图标框内。
