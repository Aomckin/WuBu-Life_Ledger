## 业务口径

- 金额整数分存储。仅启用 STORAGE 非信用卡、非 unknown 账户进入自由资金；CONSUMPTION 与信用额度均排除。
- `safe_to_spend = liquid_balance - reserved_outflow - safety_buffer`；未来收入和未收款不提前加到余额。负值显示现金流警告，安全日均为零。
- 上海自然日；无下一收入用默认 30 天固定窗口（右端不含）；存在收入则使用下一收入日，预留包含收入当天的义务。同日收入以 1 天预算计算。返回真实模式，不伪造发薪日。
- 读取虚拟展开待发生周期，不新增真实流水；必要逾期支出仍预留。完成或跳过只生成下一期，旧期完成后不重复预留。月末按上海日期截断到目标月末，后续沿截断后的日期推进。
- 历史性质为空，统计显示 UNCLASSIFIED。只有 DAILY + FIXED 计正常生活成本。新建纯耐用品购买默认 CAPITAL，周期性支出计划默认 FIXED，调用者可覆盖；不猜测旧账。退款沿原支出的性质冲减。
- 押金与代垫先记独立现金锁定 ADJUSTMENT，不算普通消费；退回不算普通收入。不可收回部分通过同事务的释放调整 + EXCEPTIONAL 支出确认损失，账户最终余额不重复扣。禁止用普通退款接口绕过损失状态。
- `record_deposit` / `create_receivable` 代表本次真实付款 / 代垫，会扣款；不是将已记过的历史支出再标记为待收。历史关联代垫迁移没有自动执行。
- 住房 consumed_cost 不含耐用品和押金；setup_cost 是其中安家 / 中介 / 搬家子集。capital_cost、deposit_locked、deposit_loss 单列；net_cash_outflow 为实际净流出。押金不进入正常生活成本。
- 凭证保存已有附件 ID 或本地引用文本；不会读取 / 上传引用文件。估计售价仅作参考，不进入账户余额。地址不上传、不解析地图。
- 消耗预测仅用最近 30 天 CONSUME / FINISH 的负数量变化，观察期从窗口起点和物品创建日较晚者起算；至少 3 次有效消耗、至少 7 天观察。数据不足返回空估计，不输出伪精确天数。PURCHASE / ADJUST / DISCARD 不计速度。低库存保留既有阈值，同时列出预计 7 天内耗尽的物品。
