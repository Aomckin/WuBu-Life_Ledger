# 物簿 v1.0 Independent Domains

RC2 使用单进程和 schema 16 SQLite。Items、Finance、Links 使用独立仓储类型，共享连接与幂等事务基础设施。

| 领域 | 写入和读取 |
| --- | --- |
| Items | `acquisitions`、`items` 与 `items/{id}/events` 保存物品、购入、退回、维护和耐用品事实。库存与对应事件同事务提交。 |
| Finance | `accounts`、`money`、`finance/refunds`、`financial`、`statements` 和 `runway` 保存账户、流水、资金约束、账单证据和语义。退款以原资金交易 ID 为依据。 |
| AI Assistance | `internal/ai` 与 `internal/media` 提供分析和转写。Intake 保存输入与建议，Items 应用经确认的库存更改。 |
| Links | `links` 保存可选多对多关系。按物品查询资金和成本使用关联派生的只读查询。购买回填先提交购入，再关联已有支出。 |

物品和资金写入各自提交。已有关联且收到退款时，退款和退货仍分别提交。取消关联只删除关联行。回填的关联步骤失败时返回已提交的购入回执，使用原请求和同一个幂等键补齐关联。

## 表归属

| 领域 | 主要表 |
| --- | --- |
| Items | items、purchase_events、purchase_items、purchase_revisions、inventory_events、durable_details、durable_events、maintenance_events、product_aliases |
| Finance | accounts、money_transactions、money_settings、money_categories、raw_financial_events、financial_event_links、financial_reviews、financial_settings、transaction_annotations、balance_checkpoints、semantic_evidence、merchant_rules、import_batches、import_batch_rows、planned_cashflows、runway_settings、residences、living_claims、residence_cost_links |
| Intake | intake_entries、intake_attachments、intake_analyses、intake_settings |
| Links 与基础设施 | domain_links、idempotency_keys、ledger_lock、migration_archive |

旧支付关联迁入 `domain_links`，历史退货数量和已移除的旧字段归档到 `migration_archive`。物品历史保留原购入价格、维护费用、售出价格和原修订记录。界面读取这些快照时按历史记录展示。维护费用外键和耐用品的财务居住外键已经移除，耐用品保留可选的居住标识。

正式应用只初始化空库或打开 schema 16。一次性迁移工具仅接受 v0.4 schema 14 的备份副本，迁移细节见 [RC2 迁移与验收](V1.0_ACCEPTANCE.md)。
