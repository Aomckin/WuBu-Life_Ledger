# 购买记录改单与删除

购买列表和购买明细均提供「改单」「删除」入口。改单可修改商家、时间、实际付款、优惠、附加费用、备注以及商品名称、包装规格、数量、单位、单价和小计；原商品行保留 ID，新行自动获得 ID。

单位输入提供瓶、罐、升、毫升、个、包、盒、袋、箱、杯、支、卷、片、克、千克、件、套、份等词条，也接受自定义。规格与名称分开：一瓶 2L 无糖可乐应记录 `name=无糖可乐, spec=2L, quantity=1, unit=瓶`；结构化保存 `package_size=2, package_unit=L`。旧的组合名称会自动拆分。

- `PUT /api/v1/purchases/{id}`：提交完整 `PurchaseAmendment`，包括最新 `expected_updated_at`、原 `source`、原 `external_id`。保留商品行的 `id` 和 `item_id`；新行不传 `id`。已关联行不能直接改物品或类型。
- `DELETE /api/v1/purchases/{id}`：JSON 请求体为 `{"expected_updated_at":"最新 updated_at"}`。逻辑删除购买并移除其费用，撤销其库存贡献；原购买与库存历史及前后快照仍保存在数据库内用于审计。
- 两种操作均支持稳定 `Idempotency-Key`。版本过期返回 409；整笔费用、商品行、库存差额、最新单价及审计快照在同一事务中提交，失败全部回滚。
- 数量修改应用购买差额，保留之后的消耗。撤销或减少导致剩余库存小于零时返回 409，需先核对库存。
- 单位更换只允许没有其他购买或独立库存变更、且全部数量来自本笔购买的物品；不能将已经消耗的升数直接换成瓶数。历史调整备注记载原单位与新单位。
- 耐用品已有维护或状态变化时不能移除对应购买；未使用耐用品删除购买后归零并归档。

朝汐适配包新增 `amend_purchase_event` 和 `delete_purchase_event`，说明中明确区分包装规格与购买数量。本次仅更新物簿仓库内 `tools/wubu_tool`，不安装或修改相邻的朝汐项目。

验证运行 `scripts/test.ps1 -ZhaoxiSource '朝汐源码的只读 src 路径'`。测试使用临时数据库，覆盖单位纠正、费用同步、库存差额、删除、幂等重试、过期版本、消耗后的冲突、共享单位、单价恢复及事务后半段失败回滚。
