# 物簿 v1.0 RC2 迁移与验收

2026-11-15。源库来自实际 v0.4 的 schema 14 在线备份，应用候选版为 1.0.0-rc.2，目标 schema 为 16。

## 可重复执行的迁移

使用已备份的 schema 14 数据库和独立的目标目录。备份应覆盖 SQLite WAL 中已提交的事务，以及引用到的同目录 `intake-tmp` 文件。真实验收副本没有外部附件文件。

```powershell
$env:PYTHONUTF8 = '1'
$env:PYTHONIOENCODING = 'utf-8'
python -B scripts/migrate-v10.py <schema14-backup.db> <staging/schema16.db>
```

工具核对 SQLite 完整性与外键，按原行号复制共享字段，并检查旧关联的两端。原字段中已去掉的引用及历史退货明细归档，幂等键和原响应 JSON 逐行保留。旧组合写入已下线，相同旧键仍会拒绝新的不同请求。第二次执行会校验已有结果。有差异时退出，避免覆盖已用过的库。

正式程序适用空库与 schema 16。双击默认读取 data/wubu.db；该路径仍是 schema 14 时，RC2 会提示迁移并退出。可以显式指定迁移后的副本，在单独端口验证启动。

```powershell
.\启动物簿.cmd -DatabasePath 'C:\wubu-staging\schema16.db' -Port 18026
```

启动新程序前先在临时目录完成迁移和核对。需要回滚时，停止应用并保留升级后的库，再把原 schema 14 备份恢复到干净路径，用原 v0.4 二进制启动。迁移后发生的新业务需按备份时点另行核对。
